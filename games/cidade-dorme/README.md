# Cidade Dorme

Jogo de dedução social para 5 a 8 pessoas, usando a TV como mesa e um celular
por jogador. Os papéis são Cidadão, Detetive, Anjo e Assassino.

## Regras desta versão

- 5–6 jogadores: 1 Assassino, 1 Detetive, 1 Anjo e os demais Cidadãos.
- 7–8 jogadores: 2 Assassinos, 1 Detetive, 1 Anjo e os demais Cidadãos.
- À noite, o Anjo protege, os Assassinos escolhem uma vítima e o Detetive
  investiga uma pessoa.
- De dia, a cidade tem 45 segundos para conversar e 30 segundos para votar.
- Empate na votação não elimina ninguém.
- A cidade vence ao eliminar todos os Assassinos. Os Assassinos vencem quando
  são tantos quanto os outros jogadores vivos.

O Anjo pode proteger a si mesmo. Papéis de eliminados só são revelados ao fim.

## Desenvolvimento

```sh
npm install
npm test
npm run dev
npm run build
```
